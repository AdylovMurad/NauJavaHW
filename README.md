# SmartLibrary — Система управления библиотекой

Цифровое приложение для автоматизации учета книг, контроля бронирования, выдачи и своевременного возврата литературы читателями.

## Технологический стек
* **Язык**: Java 21 (OpenJDK)
* **Фреймворк**: Spring Boot 3.5.6 (Data JPA, Security, MVC, Web)
* **База данных**: PostgreSQL 16
* **Шаблонизатор**: Thymeleaf
* **Тестирование**: JUnit 5, Mockito, Rest Assured, Selenium, Testcontainers

## Требования для запуска
Для успешного запуска проекта на локальной машине необходимы:
1. **Установленный Docker и Docker Compose** (для запуска базы данных и приложения в контейнерах).
2. **Запущенный демон Docker** (`sudo systemctl start docker` на Fedora/Linux).
3. **Браузер Google Chrome** (требуется только для Selenium-тестов).

## Запуск через Docker

1. Перейти в корневую директорию проекта.
2. Поднять контейнеры:
   ```bash
   docker compose up --build
   ```
3. Приложение автоматически соберется из исходных кодов и станет доступно по адресу:
   * **UI каталог книг**: http://localhost:8081/ui/books
   * **Документация Swagger (для API)**: http://localhost:8081/swagger-ui/index.html

---

Локальный запуск для разработки

1. Запустить только контейнер базы данных PostgreSQL:
```bash
docker compose up -d db
```
2. Собрать исполняемый `.jar` файл с помощью Maven:
```bash
./mvnw clean package -DskipTests
```
3. Запустить приложение, передав пароль к БД в качестве переменной окружения:
```bash
DB_PASSWORD=docker_password java -jar target/NauJava-0.0.1-SNAPSHOT.jar
```

## Тестирование проекта

1. Запуск стандартных тестов (Юнит-тесты + Интеграция с Testcontainers)
Интеграционные тесты автоматически запустят временный контейнер PostgreSQL в Docker:
```bash
./mvnw clean test
```
2. Запуск интеграционных тестов вместе с UI-тестами (Selenium):
```bash
DOCKER_API_VERSION=1.40 ./mvnw clean test -Dui.tests=true
```

## Учетные данные для входа (По умолчанию)
При первом старте система автоматически создает учетную запись администратора со следующими параметрами:
* **Логин (username)**: admin
* **Пароль**: adminpass

## Доступные разделы и карта страниц

### Публичные разделы (Доступны гостям и читателям)
* **Регистрация**: http://localhost:8081/registration — создание нового аккаунта читателя.
* **Вход в систему**: http://localhost:8081/login — форма аутентификации.
* **Каталог книг**: http://localhost:8081/ui/books — витрина доступных книг с фильтрами.
* **Личный кабинет**: http://localhost:8081/ui/profile — список забронированных и взятых книг.

### Панель администратора (Доступна только с ролью `ROLE_ADMIN`)
* **Управление книгами**: http://localhost:8081/admin/books — добавление, изменение и удаление книг.
* **Управление авторами**: http://localhost:8081/admin/authors — CRUD авторов.
* **Управление жанрами**: http://localhost:8081/admin/genres — CRUD жанров.
* **Список читателей**: http://localhost:8081/admin/users — просмотр зарегистрированных пользователей.
* **Контроль выдач**: http://localhost:8081/admin/loans — обработка выдач и возвратов книг.
* **Статистика и отчеты**: http://localhost:8081/admin/stats — числовые показатели и асинхронный генератор HTML-отчетов.

## Пользовательские сценарии

### Действия читателя (пользователя)
1. **Регистрация**: Перейдите на страницу `/registration`, введите уникальный логин, почту, имя, фамилию и пароль. Нажмите кнопку «Зарегистрироваться». Вас перенаправит на форму входа.
2. **Вход**: Введите логин и пароль созданного пользователя на странице `/login`.
3. **Поиск литературы**: Перейдите в каталог `/ui/books`. Используйте фильтры в верхней части экрана (название, автор, жанр) и нажмите «Фильтровать» для поиска нужного издания.
4. **Резервирование**: Найдите книгу, у которой показатель «Доступно» больше 0. Нажмите кнопку «Забронировать». Статус книги обновится, а ее доступное количество уменьшится на 1.
5. **Просмотр личного кабинета**: Перейдите на страницу профиля `/ui/profile` (или нажмите ссылку «Личный кабинет» из каталога). Здесь отображается список ваших забронированных книг, текущий статус (например, `BOOKED` или `BORROWED`) и срок, до которого необходимо вернуть литературу.

### Действия библиотекаря (администратора)
1. **Вход**: Выполните вход на странице `/login` под учетными данными администратора (`admin` / `adminpass`).
2. **Наполнение каталога**: 
   * Перейдите в раздел `/admin/authors` и добавьте нового автора.
   * Перейдите в раздел `/admin/genres` и добавьте жанр.
   * Перейдите в раздел `/admin/books`, введите название книги, выберите автора и жанр из выпадающих списков, укажите количество экземпляров и нажмите «Добавить».
3. **Оформление выдачи**: Когда читатель приходит в физическую библиотеку за забронированной книгой, перейдите в раздел `/admin/loans`. Найдите нужную бронь в верхней таблице («Бронирования») и нажмите кнопку **«Выдать»**. Статус брони изменится на `BORROWED` (Выдано).
4. **Оформление возврата**: Когда читатель приносит книгу обратно, перейдите в `/admin/loans`, найдите запись в таблице «Выданные книги» (или «Просроченные») и нажмите кнопку **«Вернуть»**. Запись закроется (статус `RETURNED`), а доступный баланс экземпляров этой книги в каталоге автоматически увеличится на 1.
5. **Анализ работы и выгрузка отчетов**:
   * Перейдите в раздел `/admin/stats`. Здесь представлена актуальная статистика по активным выдачам и должникам.
   * Нажмите кнопку **«Сформировать отчет»**. Система асинхронно соберет детальные данные по базе. Нажмите появившуюся ссылку «Открыть», чтобы просмотреть готовый HTML-отчет со статистикой времени выполнения операций.
